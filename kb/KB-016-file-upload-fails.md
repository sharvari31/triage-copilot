# File upload fails

The maximum file size is 25 MB per file. Supported formats are PDF, PNG, JPG, DOCX and CSV. Uploads fail if the file name contains special characters such as # or %, or if the connection drops; try renaming the file and using a stable network. Corporate proxies may block uploads larger than 10 MB.
