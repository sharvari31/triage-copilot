# Package marked delivered but not received

Check with neighbours, building security and any safe place you listed. Couriers sometimes mark a package delivered up to 24 hours early, so wait one day. If it still has not arrived, report it within 7 days of the delivered date from **Orders > Report a problem**. We open a courier investigation and, if the package is not found within 5 business days, send a replacement or a full refund.
