# Data not syncing between mobile and web

Sync runs every few seconds when online. Pull down to refresh on mobile, and make sure both devices are signed in to the same account. Offline changes upload when the device reconnects; if the same item was edited on two devices, the most recent edit wins and the other is kept in **Version history**. Signing out and back in forces a full resync.
