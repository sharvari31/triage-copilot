# Website not loading or showing errors

First check status.example.com for ongoing incidents. If there is none, hard-refresh the page (Ctrl+Shift+R), disable browser extensions such as ad blockers, and try an incognito window. Supported browsers are the latest two versions of Chrome, Edge, Firefox and Safari. If you see an error code like 500 or 502, include it with the time it happened when contacting support.
